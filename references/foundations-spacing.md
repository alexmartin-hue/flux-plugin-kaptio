# Spacing

A 4px-based scale. Every spacing value is a multiple of 4px (0.25rem),
creating consistent vertical and horizontal rhythm across all Kaptio products.

--flux-space-1 0.25rem (4px)  Tight gaps

--flux-space-2 0.5rem (8px)  Inline spacing

--flux-space-3 0.75rem (12px)  Compact padding

--flux-space-4 1rem (16px)  Default gap

--flux-space-5 1.25rem (20px)        --flux-space-6 1.5rem (24px)  Card padding

--flux-space-8 2rem (32px)  Section gap

--flux-space-10 2.5rem (40px)        --flux-space-12 3rem (48px)  Large section gap

--flux-space-16 4rem (64px)  Page section

--flux-space-20 5rem (80px)        --flux-space-24 6rem (96px)  Hero spacing
