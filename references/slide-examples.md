# Slide examples

Canonical examples for slides that appear often in sales, marketing, and enablement decks.
Match typography, color, and spacing to Flux foundations; use these pages as the single
reference when building or reviewing presentations.

AI tools: clone these templates instead of composing slides from scratch — raw source is
served at `/slide-examples/source/.txt`; the routing table lives on
[For AI](/for-ai).
